================================================================================
  PHYSIOPLANER – Bedienungsanleitung
  Hausaufgaben-Generator für die Physiotherapie
================================================================================

Willkommen bei PhysioPlaner!

Diese Anleitung erklärt Schritt für Schritt, wie du die App nutzt –
ganz ohne Computerkenntnisse.


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  ERSTE SCHRITTE – EINMALIGE EINRICHTUNG
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Die App besteht aus einer einzigen Datei: index.html

Schritt 1: Datei öffnen
  Doppelklicke auf "index.html" – die App öffnet sich im Browser.
  Du brauchst nichts zu installieren.

Schritt 2: API Key eintragen (nur beim ersten Mal)
  Die App nutzt eine KI (Google Gemini), um die Pläne zu erstellen.
  Dafür brauchst du einen kostenlosen Zugangscode (API Key).

  ┌─────────────────────────────────────────────────────────────────┐
  │  So bekommst du deinen API Key (einmalig, ca. 2 Minuten):      │
  │                                                                 │
  │  1. Gehe auf: https://aistudio.google.com/app/apikey           │
  │  2. Melde dich mit deinem Google-Konto an                      │
  │  3. Klicke auf "Create API Key"                                 │
  │  4. Kopiere den langen Code (beginnt mit "AIza...")             │
  └─────────────────────────────────────────────────────────────────┘

  Den Code in die App eintragen:
  → Klicke auf das Zahnrad-Symbol (⚙) oben rechts in der App
  → Füge den Code in das Feld ein
  → Klicke auf "Speichern"
  → Fertig! Der Code bleibt gespeichert, du musst das nie wieder machen.


━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
  EINEN HAUSAUFGABENPLAN ERSTELLEN
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Du bist auf dem Tab "Plan erstellen" (wird beim Öffnen direkt angezeigt).

Schritt 1: Patient eintragen
  Im Feld "Patient" gibst du Name und Alter ein.
  Beispiel:  Maria M., 45 Jahre

Schritt 2: Diagnose / Ziel eintragen
  Im Feld "Diagnose / Ziel" beschreibst du kurz das Therapieziel.
  Beispiel:  LWS-Syndrom, Kräftigung der Rumpfmuskulatur

Schritt 3: Übungen eintragen
  Im Feld "Gewünschte Übungen" gibst du die Übungen kommagetrennt ein.
  Beispiel:  Brücke, Plank, Schulterkreisen, Kniebeuge

  TIPP: Die KI kennt auch englische Namen und Synonyme.
  "Plank", "Unterarmstütz" und "Planke" sind für die KI dasselbe.

Schritt 4: Plan generieren
  Klicke auf den blauen Button "Plan generieren".
  Die KI braucht etwa 5–15 Sekunden.

Schritt 5: Plan als Word-Datei herunterladen
  Sobald der Plan angezeigt wird, klicke auf:
  "↓ Als Word exportieren (.docx)"

  Die Datei wird automatisch heruntergeladen und enthält:
  - Patientenname und Datum im Dateinamen
    (Beispiel: Hausaufgaben_Maria_M._19-04-2026.docx)
  - Alle Übungen gegliedert in Warm-up, Lockerung / Beweglichkeit, Kräftigung
  - Saubere Formatierung, direkt druckbereit

Schritt 6: Word-Datei vor dem Drucken bearbeiten (optional)
  Die heruntergeladene Datei öffnest du in Microsoft Word oder LibreOffice.
  Dort kannst du den Plan vor dem Ausdrucken noch anpassen:

  - Einzelne Übungen streichen oder ergänzen
  - Texte umformulieren oder kürzen
  - Wiederholungen für bestimmte Übungen individuell ändern
  - Logo oder Name der Praxis einfügen
  - Bilder oder Zeichnungen zur Veranschaulichung hinzufügen
  - Persönliche Notizen für den Patienten ergänzen

  Danach speichern und ausdrucken oder per E-Mail an den Patienten schicken.

  TIPP – Wo wird die Datei gespeichert?
  ──────────────────────────────────────
  Die App setzt automatisch den Dateinamen (Patient + Datum), aber der
  Speicherordner wird vom Browser festgelegt – nicht von der App.

  Standard: Die Datei landet im "Downloads"-Ordner deines Computers.

  Wenn du bei jedem Export selbst wählen möchtest wo die Datei gespeichert
  wird (empfohlen für bessere Ordnung), stelle das einmalig im Browser ein:

  Chrome / Edge:
    Einstellungen → Downloads →
    "Vor dem Herunterladen fragen, wo die Datei gespeichert werden soll" → AN

  Firefox:
    Einstellungen → Allgemein → Downloads →
    "Jedes Mal nachfragen, wo eine Datei gespeichert werden soll" → AN

  Danach öffnet sich bei jedem Word-Export automatisch ein Speichern-Dialog.

  ÜBUNGSDATENBANK VERWALTEN
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Klicke oben auf den Tab "Übungsdatenbank".

Hier sammelst du deine eigenen Übungsbeschreibungen.
Je mehr Übungen du einträgst, desto genauer werden die generierten Pläne –
denn die KI nutzt bevorzugt DEINE Beschreibungen.


NEUE ÜBUNG HINZUFÜGEN
  1. Klicke auf "+ Neue Übung"
  2. Fülle die drei Felder aus:

     Name:         Vollständiger Übungsname
                   Beispiel:  Brücke (Gluteal Bridge)

     Kategorie:    Wähle aus: Warm-up / Lockerung / Kräftigung

     Beschreibung: Deine bewährte Erklärung der Übung
                   Schreibe alles rein, was du dem Patienten erklären würdest:
                   Ausgangsstellung, Bewegungsablauf, Wiederholungen, Tipps.

  3. Klicke auf "Speichern"

ÜBUNG BEARBEITEN
  Klicke beim entsprechenden Eintrag auf "Bearbeiten",
  ändere was du möchtest, dann "Speichern".

ÜBUNG LÖSCHEN
  Klicke auf "Löschen" – du wirst noch einmal gefragt, ob du sicher bist.

ÜBUNGEN SUCHEN
  Tippe oben in das Suchfeld – die Liste wird sofort gefiltert.

  BACKUP – DATENBANK SICHERN UND ÜBERTRAGEN
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

WICHTIG: Die Übungsdatenbank ist im Browser gespeichert.
Bei einem Computerwechsel oder einem neuen Browser muss sie einmalig
übertragen werden. Das geht ganz einfach:


BACKUP ERSTELLEN (regelmäßig empfohlen, z.B. einmal im Monat)
  → Tab "Übungsdatenbank" öffnen
  → Klick auf "↓ Backup"
  → Eine Datei wird heruntergeladen:
    "physio_datenbank_TT-MM-JJJJ.json"
  → Diese Datei an einem sicheren Ort ablegen:
    USB-Stick, externer Speicher, Cloud (OneDrive, Google Drive), E-Mail

BACKUP WIEDERHERSTELLEN (z.B. nach Computerwechsel)
  1. index.html auf dem neuen Computer öffnen
  2. API Key in den Einstellungen (⚙) neu eintragen
  3. Tab "Übungsdatenbank" öffnen
  4. Klick auf "↑ Importieren"
  5. Backup-Datei auswählen
  6. Auswahl:
     → OK drücken:       Übungen werden zu vorhandenen hinzugefügt
     → Abbrechen drücken: Bestehende Daten werden ersetzt (nur importierte)
  7. Alle Übungen sind wieder da!

  HÄUFIGE FRAGEN
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

F: Die KI zeigt eine Fehlermeldung "Ungültiger API Key"
A: Zahnrad (⚙) → API Key prüfen und neu einfügen.
   Achte darauf, den gesamten Code ohne Leerzeichen am Anfang/Ende einzufügen.

F: Die KI antwortet nicht oder es dauert sehr lange
A: Prüfe die Internetverbindung. Dann erneut auf "Plan generieren" klicken.
   Falls "Rate Limit" angezeigt wird: 1–2 Minuten warten und es nochmal versuchen.

F: Der Word-Export klappt nicht
A: Prüfe ob eine Internetverbindung besteht (die Export-Funktion braucht kurz
   das Internet beim ersten Laden). Browser-Seite neu laden und nochmal versuchen.

F: Ich habe versehentlich eine Übung gelöscht
A: Falls du ein Backup hast, einfach importieren (Modus "Hinzufügen").
   → Empfehlung: Regelmäßig Backups erstellen!

F: Werden meine Patientendaten irgendwo gespeichert?
A: Nein. Patientennamen und Diagnosen werden nur kurz an die KI gesendet,
   um den Plan zu erstellen. Sie werden nicht dauerhaft gespeichert.
   Die KI-Verbindung läuft direkt zu Google – keine Weitergabe an Dritte.

F: Kann ich die App auf mehreren Computern nutzen?
A: Ja. Kopiere einfach die index.html auf jeden Computer und spiele dein
   aktuelles Backup ein. Beide Computer haben dann dieselbe Datenbank.

F: Die App startet nicht / der Browser zeigt eine leere Seite
A: Versuche einen anderen Browser (Chrome oder Edge empfohlen).
   Falls ein Sicherheitsprogramm blockiert: Die Datei ist sicher, sie läuft
   vollständig lokal ohne Installation.
